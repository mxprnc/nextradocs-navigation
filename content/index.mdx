## Dailyfeed
Spring Boot, Java, kubernetes, kafka, helm 기반의 쿠버네티스 프로젝트입니다. 여러가지 기술적으로 느낀 관점들을 프로젝트로 녹여냈던 사이드프로젝트입니다. 코드레벨,설계관점 외에도 gradle 멀티모듈기반의 프로젝트의 조합을 helm 으로 어떻게 여러 차트들을 관리할지, 멀티모듈을 어떻게 구성해서 관리가 용이하게 할지 등을 고민을 많이했던 프로젝트입니다.
- https://github.com/mxprnc/dailyfeed-readme-season1
- https://nextradocs-dailyfeed-season1.vercel.app/

## Webflux, R2dbc

Webflux 를 이야기하다보면 스레드, 코루틴 이야기를 많이 하게 되는 것 같습니다.<br/>
개인적으로는 스레드,코루틴은 메모리를 공유하는 개념이기에 하나의 프로세스 내에서 장애 발생시 전체 장애로 전파된다고 느껴서... 너무 헤비하게 스레드,코루틴 프로그래밍에 집중하기보다 프로세스(컨테이너)를 잘 조직해서 스케일 아웃을 통해 프로세스,스레드의 장점을 적절하게 병행하는게 좋다고 생각하긴 합니다.<br/>
